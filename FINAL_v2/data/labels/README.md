# Human labels

Generated by `shared/scripts/02_make_label_sample.py --stratify dataset --per-dataset 50 --allocation proportional --disagree-share 0.25 --n 400 --pilot 30 --seed 20260923 --block-size 50`.
Design: 50 distinct questions per dataset, random within question sub-types with proportional allocation, one model's answer per question with models balanced; graders record a rating from 1 to 7, converted afterwards to a utility on the 0-1 line, (rating - 1) / 6 (`shared/scripts/label_scale.py`).

* `labeller_sheet.csv` - the one blind main sheet every grader receives: 1550 rows in 31 blocks of 50 (`block` column; one online form per block). No rows are assigned to anyone: any number of graders take part, each identified by their email address (stored only as a code), and each does whole blocks. Graders fill `rating` (1 to 7), `hedged`, `note`.
* `pilot_30.csv` - the calibration pilot, done first by every grader and discussed before the main sheet.
* `handoff/grader_kit.zip` (from `04_make_labeller_handoff.py`) - the one zip to give every grader: walkthrough, guide, pilot and main sheets (xlsx + csv).
* Never share `sample_master.csv` / `pilot_master.csv`: they name the model and carry the judge's scores.
* After labelling: `uv run python shared/scripts/03_label_agreement.py` reports agreement, writes the adjudication queue, and (once `adjudicated.csv` exists) merges everything into `human_labels.csv` for the pipelines.

* `forms_images/` (not in git; `uv run python shared/scripts/06_render_row_images.py`) - one card per row and the scale table as PNG, for the Google Forms route.

Documents: `notes/LABELLING_GUIDE_FOR_LABELLERS.md` (the rules given to graders), `notes/WALKTHROUGH_LABELLERS.md` (their procedure), `notes/WALKTHROUGH_COORDINATOR.md` (yours), `notes/GOOGLE_FORMS_OPTION.md` (the online-form route), `notes/HUMAN_LABELLING_PROTOCOL.md` (design and reporting).
